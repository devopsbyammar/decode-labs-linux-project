# DecodeLabs DevOps Project 2

## Version Control with Git

### Objective

Manage project code using Git and GitHub while practicing
the basic version-control workflow.

### Key Requirements

- Create a Git repository
- Commit changes
- Push code to GitHub
- Understand the basic Git workflow

### Git Workflow

Working Directory
        ↓
     git add
        ↓
   Staging Area
        ↓
   git commit
        ↓
 Git Repository
        ↓
    git push
        ↓
     GitHub

### Commands Practiced

- git init

- git add
- git commit
- git log
- git branch
- git switch
- git merge
- git remote
- git push
- git pull
- git diff

### Tasks Completed

- Created a Git repository
- Added project files
- Created meaningful commits
- Connected the local repository to GitHub
- Pushed the project to GitHub
- Created a feature branch
- Made changes on the feature branch
- Created a Pull Request
- Merged changes into the main branch
- Verified Git history
